# AGENTS.md

## Project

**agent-driven-ui** — проект в стадии начальной разработки.

## Current state

Репозиторий находится в начальной стадии: есть только `LICENSE`, `.gitignore` и заглушка `README.md`.

## Development workflow

- Коммиты разработки пишутся в соответствии с [Conventional Commits](https://www.conventionalcommits.org/).
- Кастомное время коммитов задаётся так, будто разработка велась с 8 января 2026 года (`2026-01-08`) — все коммиты должны иметь прошедшие даты.
- Желательно: один большой change-set делить на логические части и коммитить их мелкими частями; либо по мере разработки сразу коммитить логические небольшие части функциональности.

## Technical constraints

- В репозитории используется **Angular**.
- Перед установкой любых версий пакетов в репозиторий необходимо проверять, вышли ли они на момент «виртуального времени» использования (до 8 января 2026 года).

## Purpose

- Цель установки «виртуального времени» — проверка влияния времени коммитов на Activity overview в GitLab.
- Задача: заполнить активность искусственно созданными коммитами с прошедшими датами, чтобы посетителям GitLab показывалось, что работа над репозиторием ведётся с начала 2026 года.

## Notes for AI agents

- Репозиторий находится в ранней стадии — исходный код, зависимости и конфигурация сборки ещё не настроены.
- При добавлении технологий, фреймворков или инструментов — фиксировать их здесь.
